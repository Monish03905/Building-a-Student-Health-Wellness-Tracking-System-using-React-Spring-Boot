## 📋 Prerequisites

Before you begin, ensure you have the following installed on your local development machine:

### Frontend
* **Node.js** (v16.0.0 or higher recommended) - [Download Node.js](https://nodejs.org/)
* **npm** (comes with Node.js) or **Yarn** - For managing frontend dependencies.
* **Git** - For version control.

### Backend (If applicable)
* **Java Development Kit (JDK)** (v11 or higher) - [Download JDK](https://www.oracle.com/java/technologies/downloads/)
* **Maven** - For building the backend and managing Spring Boot/Hibernate dependencies.
* **Database:** Ensure your local database server (e.g., MySQL, PostgreSQL) is installed and running.
