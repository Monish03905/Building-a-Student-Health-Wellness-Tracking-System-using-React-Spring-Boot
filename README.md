Student Health & Wellness Tracking System
A Student Health & Wellness Tracking System designed to help students monitor and manage their physical and mental wellness. The platform allows users to track daily health metrics, maintain wellness records, and gain insights into their overall well-being.
This project demonstrates the use of modern web technologies to build a responsive and user-friendly health monitoring application.


Live Demo


Deployed Application: https://wellnes-tracker.netlify.app/
GitHub Repository: https://github.com/Monish03905/Building-a-Student-Health-Wellness-Tracking-System-using-React-Spring-Boot

Project Overview:


The Student Health & Wellness Tracking System enables students to:
Track daily health activities
Monitor wellness indicators
Maintain health records
Improve awareness of personal well-being
Encourage healthy habits through consistent tracking
The application is designed with a clean UI, responsive layout, and scalable backend structure.
Features
User-friendly dashboard
Health data tracking
Wellness activity monitoring
Responsive design (mobile and desktop)
Secure data management
Scalable architecture for future improvements
